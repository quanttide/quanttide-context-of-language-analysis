# quanttide-context-of-language-analysis

量潮语言分析语境——语言分析领域的上下文背景与关联语境。

## 定位：驱动层

context 是语言分析系统的驱动层：系统（人或 AI）执行任何工作时读取的背景设定——当前在做什么、依据什么规则、处于哪个阶段、注意什么边界。它回答「带着什么上下文干活」。

与同域数据资产的分工：

| 资产 | 承担 | 问题 |
|---|---|---|
| **context（本仓库）** | 驱动 | 现在带着什么上下文干活？ |
| journal | 时间线 | 这段时间发生了什么、状态怎么变 |
| archive | 沉淀 | 已归档的成品与过程材料 |
| brochure | 对外 | 对外怎么介绍我们 |

## 内容形态

无时态：只保留当前生效的驱动规则，不堆积历史——旧版本删除，变更过程由 journal 的时间线记录。

按主题组织语境文档（驱动规则、当前阶段、工作约定），每篇独立可被系统加载。
